# Fees

| --- | --- |
| $1,000 | 0.5% |
| $10,000 | 0.4% |
| $100,000 | 0.3% |

## Profit Fees

Fees are deducted only on successful investments and only from profit, not from capital.

One third of the fees are deducted yearly. The remaining two thirds are deducted when the user withdraws money.

Current static profit fee: 1.5%.

| Profit up to | Fee |
| --- | --- |
| $10,000 | 1.5% |
| $100,000 | 1.4% |
| $1,000,000 | 1.3% |
| $10,000,000 | 1.2% |
| $100,000,000 | 1.1% |
| $1,000,000,000 | 1% |
